## processed/ — обработанные данные

| Файл | Что внутри |
|---|---|
| `astana_features.csv` | очищенный набор с признаками: 16 779 строк × 69 столбцов. Цель `price_local` (₸); `price_per_m2_kzt` — цена за м² в ₸, только для анализа; `listing_id` — номер объявления; `district_listing` — район из объявления (до сверки); остальное — признаки из словаря |
| `feature_dictionary.csv` | словарь признаков: 65 строк (признак, группа, тип, описание, доля пропусков, число уникальных значений) |
| `holdout_split.csv` | разбиение на обучение и тест по `listing_id`: 13 423 и 3 356 строк, seed 42 |
| `cache/` | промежуточные результаты тяжёлых шагов блокнота (joblib); можно удалить — блокнот пересчитает |
